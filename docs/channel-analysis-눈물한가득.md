## 1. 채널 콘셉트

- **"울리는 영화 쇼츠" 한 가지만 합니다.** 채널 이름 자체가 약속("눈물 한가득")입니다. 장르는 섞이지만(좀비, SF, 전쟁, 로맨스) 공통점은 모두 **감동·희생·가족·치유**로 끝난다는 점입니다.
- **영화 정보가 아니라 "인생 교훈"을 팝니다.** 제목에 영화 이름이 한 번도 안 나옵니다. 영화 리뷰 채널이 아니라 "사람 사는 이야기" 채널처럼 포지셔닝되어 있습니다. 그래서 영화를 모르는 중장년층도 공감형으로 소비합니다.
- **고정 템플릿**을 씁니다. 모든 영상이 똑같은 극장 프레임(위쪽 붉은 커튼, 아래쪽 객석, 가운데 영상)입니다. 피드에서 한눈에 이 채널 영상임을 알아볼 수 있습니다.
- **글로벌 확장:** 한국어로 만들지만 제목을 영어로 현지화하고 영어 자동 더빙 트랙을 켜 둡니다. 해외 피드에도 노출됩니다. 최근 일부 영상(8개)은 영어 제목이 없는데, 이 영상들의 조회수가 대체로 낮습니다(28만~1,000만, 중앙값 약 220만).

## 4. 썸네일 패턴

쇼츠라서 별도 썸네일 없이 **영상 첫 프레임이 곧 썸네일**입니다. 템플릿이 고정이라 모든 썸네일 구조가 같습니다.

```
┌────────────────────┐
│ ▒▒ 붉은 커튼 ▒▒▒▒ │  ← 검은 바탕
│  제목 1줄 (흰색)   │  ← 굵은 고딕, 검은 외곽선
│  제목 2줄 (노란색) │  ← 핵심 단어가 여기 들어감
├────────────────────┤
│                    │
│   영화 장면        │  ← 화면의 약 40~45%, 인물 클로즈업
│  (한 줄 대사 자막) │  ← 흰/노랑/연두 글자 + 검은 외곽선
├────────────────────┤
│ ▒▒ 극장 객석 ▒▒▒▒ │
└────────────────────┘
```

**조회수 상위 12개 vs 하위 12개 썸네일 비교**

| | 상위 | 하위 |
|---|---|---|
| 인물 | **아이·노인·환자** 얼굴 클로즈업 (웃는 소녀, 노인 분장, 병상의 여성) | 중년 남성 배우, 무표정, 옆모습 |
| 감정 | 눈물 직전, 경외, 미소 등 표정이 뚜렷함 | 대화 중인 평범한 표정 |
| 화면 속 자막 | 있음 ("나한텐 마지막 소원이 있었어" 같은 감정 대사) | 대부분 없음 |
| 스타 배우 | 적음 | 많음 (안토니오 반데라스, 톰 행크스, 브라이언 크랜스턴 등) |

스타 얼굴은 클릭을 부르지 못했습니다. **"누군지 모르는 약자의 표정"**이 더 강했습니다.

## 5. 영상 구성 (타임라인)

1위 영상의 스토리보드와 74개 자막 타임라인에서 뽑은 공통 구조입니다.

| 구간 | 시간 | 내용 |
|---|---|---|
| **① 콜드 오픈 훅** | 0~4초 | 사건이 터지는 장면부터 시작. 내레이션 첫 줄이 평균 **3.5초**에 들어옴. "~하는 남자.", "갑자기 ~" 처럼 명사로 끝나는 한 문장 |
| **② 배경 설명** | 4~20초 | "사실 그녀는 시한부였죠." / "그러나 ~" 로 인물의 사연 공개 |
| **③ 전개 (요약 내레이션)** | 20~60초 | "그렇게 ~", "그러던 어느 날 ~" 으로 시간을 건너뜀. 내레이션 사이사이에 원본 대사를 짧게 끼움 |
| **④ 원본 대사 구간** | 60~130초 | **내레이션을 멈추고 영화 원본 음성 + 한국어 자막**으로 감정 클라이맥스를 보여줌. 수십 초 동안 이어지기도 함 |
| **⑤ 마무리** | 마지막 5~15초 | 두 가지 방식 중 하나(아래) |

**마무리 방식의 변화**

- **초기(6월):** 질문형 결말. "여러분은 이런 상황에서 ~하실 수 있나요?" (예: 편견에 찌든 남자가 노숙자에게 배운 교훈, 돈을 많이 벌어도 행복하지 않은 이유)
- **7월 이후:** **클리프행어형**으로 바뀜. "~를 발견하는데", "마지막으로 한마디를" 처럼 **문장 중간에 끊고 끝냄**. 그 결과 끝까지 본 사람이 다시 돌려보거나("루프") 댓글로 결말을 묻게 만듭니다. 최근 대부분이 이 방식입니다.

**두 가지 포맷**

| 포맷 | 영상 수 | 조회수 중앙값 | 특징 |
|---|---|---|---|
| A. 내레이션 요약형 | 64 | 505만 | 위 타임라인 그대로 |
| B. 무(無)내레이션 장면형 | 10 | 630만 | 내레이션 없이 한 장면을 통째로 보여주고 대사를 한국어로 처리. 자막 인식 결과를 보면 **한국어 음성(더빙 추정)**이 들어간 것으로 보임 |

B형은 편차가 큽니다. 룸(1,737만)처럼 장면 하나만으로 충분히 강한 영화는 대박이 났고, "부당함을 목격하고도…"(41만), "원하는 것을 얻어내는…"(85만)처럼 설명 없이는 맥락이 안 잡히는 대화 장면은 망했습니다.

**말투 규칙 정리**

1. **첫 문장은 명사로 끝냅니다.** "매일같이 노숙자를 도와주는 남자." / "교통사고로 언니를 잃은 뒤 계속 힘들어하는 바이올렛."
2. **본문은 "~죠" 체(해요체의 구어형)**로, 담담하게 전달합니다. 과장된 감탄사는 거의 없습니다.
3. **"~는데"로 긴장을 이어가며** 컷을 넘깁니다. 한 문장이 끝나기 전에 장면이 바뀝니다.
4. **인물 이름은 외국 이름 그대로** 부릅니다(벤자민, 다니엘, 핀치). 영화 제목은 절대 말하지 않습니다.
5. **감정 해설은 하지 않습니다.** "슬프다", "감동적이다" 같은 말 대신 사건만 말하고, 감정은 원본 대사와 배우 표정에 맡깁니다.
6. 목소리: 자막 인식에 이름·발음 오류가 꽤 많은 것으로 보아(예: "노숲자", "시안부") **TTS(AI 음성) 가능성이 높습니다.** 낮고 차분한 톤입니다.

## 10. 저작권 대응 (관찰 + 주의)

### 관찰된 사실

- 설명란이 **완전히 비어 있습니다.** 출처, 영화 제목, 배급사 표기가 없습니다.

- 원본 영상이 화면의 절반 이하로 줄어든 채 템플릿 안에 들어가고, 내레이션과 자막이 덧붙습니다.
- 원본 영화 음성과 음악을 그대로 씁니다.
- **클레임이나 경고를 받고 있는지, 수익이 누구에게 가는지는 외부에서 확인할 수 없습니다.**

### 이 방식을 그대로 따라 하면 안 되는 이유

위 방식들은 저작권 문제를 **해결해 주지 않습니다.** 영화 장면을 허락 없이 2~3분씩 쓰는 것은 요약 방식과 상관없이 권리자가 문제 삼을 수 있습니다.

- 권리자가 Content ID로 클레임을 걸면 **수익이 권리자에게 가거나 영상이 차단**됩니다. 조회수가 많아도 내 수익은 0일 수 있습니다.
- 권리자가 직접 신고(삭제 요청)하면 **저작권 경고**가 쌓이고, **90일 안에 3회면 채널이 삭제**됩니다. 배급사가 한 채널의 영상을 한꺼번에 신고해 채널이 하루아침에 사라지는 일은 영화 요약 채널에서 흔합니다.
- 한국 저작권법의 공정이용(제35조의5)은 사안마다 따로 판단합니다. "2분 요약 + 내레이션"이 공정이용으로 인정된다는 보장은 없고, **원작 시장을 대체하는 결말 공개형 요약은 불리하게 판단될 가능성이 큽니다.**
- 출처를 숨기는 것(설명란 비우기, 제목 숨기기)은 법적 보호가 되지 않습니다. 오히려 영화 홍보 효과가 사라져서 권리자가 너그럽게 볼 이유도 줄어듭니다.

### 안전하게 가는 방법 (권장 순서)

1. **공식 허용 소스 활용:** 배급사·스튜디오가 공개한 예고편, 보도용 클립(EPK), 공식 채널의 클립은 이용 조건을 확인하고 씁니다. 일부 국내 수입·배급사는 제휴·홍보 목적의 클립 사용을 허락해 주니 **메일로 문의해 보세요**(신작 개봉 홍보 시즌에 특히 잘 됩니다).
2. **퍼블릭 도메인 영화:** 저작권이 끝난 고전 영화(미국 기준 1920년대 이전 공개작 등)는 자유롭게 쓸 수 있습니다. 시간·운명을 다룬 고전도 꽤 있습니다.
3. **해설 비중을 크게 높이기:** 원본은 짧게 인용하고, 내 분석·해석·비교가 중심이 되게 합니다. 결말 전체를 보여주지 않고 "이 영화를 봐야 하는 이유"로 끝내면 공정이용 판단에도 유리하고 원작 홍보 효과도 생깁니다.
4. **출처 표기:** 설명란에 영화 제목·연도·배급사를 적습니다. 법적 면책은 아니지만 권리자와의 관계에 유리하고, 영화 제목 검색 유입도 생깁니다.

### 11-6. 운영 계획

| 항목 | 권장 |
|---|---|
| 업로드 | 처음 2주는 매일(알고리즘 테스트) → 이후 **이틀에 1개**, 오후 6시 |
| 길이 | 130~150초 |
| 현지화 | 영어 제목 필수, 가능하면 영어 자동 더빙 켜기 |
| 설명란 | 영화 제목·연도·출처 표기 (이 채널과 반대로) |

| 확장 | 조회수 1,000만을 넘긴 영화가 나오면 같은 영화의 다른 장면으로 2~3편 연작 |

### 11-7. 이 저장소로 바로 만들 수 있는 것

이 저장소의 쇼츠 생성기(`src/make.py`)는 이미 세로 변환, 자막 굽기, 훅 문구, BGM 더킹을 지원합니다. 위 스타일을 위해 추가하면 좋은 기능은 다음과 같습니다.

1. **고정 배경 템플릿 PNG 위에 영상을 올리는 `source.fit = "template"` 모드** (상단 제목 영역 + 하단 장식)
2. **영상 전체 길이 동안 떠 있는 2줄 제목** (1줄/2줄 색상 따로 지정)
3. **화자별 자막 색상** (SRT 안에 화자 태그를 넣으면 색을 바꿔 주기)
4. **TTS 내레이션 트랙 + 원본 음성 자동 더킹**

필요하면 이 기능들을 프리셋(`presets/time-tearjerker.json`)으로 이어서 구현해 드릴 수 있습니다.

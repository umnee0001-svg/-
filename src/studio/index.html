업로드 명령

AI 체크 (제목·설명·썸네일 검토)

console.anthropic.com 에서 발급합니다. 이 컴퓨터의 studio.config.json 에만 저장되고 git 에는 올라가지 않습니다. 검토 한 번에 보통 수십 원 정도의 사용료가 듭니다.
AI 가 검토할 때 채널 성격과 시청자를 참고합니다.

쓸 수 있는 자리표시자

업로드할 때 실제 값으로 바뀝니다. 값이 비어 있으면 (예: 썸네일 없음) 바로 앞의 --옵션 과 함께 빠집니다.

{video}영상 파일 경로
{thumbnail}썸네일 파일 경로
{title}제목
{description}설명 (글자 그대로)
{description_file}설명이 담긴 .txt 파일 경로
{tags}태그 (쉼표로 이어 붙임)
{privacy}private / unlisted / public
{publish_at}예약 공개 시각
{meta}위 정보를 모두 담은 .json 파일 경로

업로드할 때마다 영상 옆에 영상이름.upload.json 과 영상이름.description.txt 가 같이 저장됩니다.
